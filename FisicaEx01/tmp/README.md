# Arquivos de desenvolvimento

Esta pasta conserva os materiais usados para criar e revisar o relatório. **Nenhum arquivo daqui precisa ser aberto para ler a versão final**: ela está em [`../Relatório_Final.pdf`](../Relatório_Final.pdf).

## `relatoriot0/`

- `criar_relatorio.py`, `criar_formulas.py`, `criar_tabelas.py` e `resolucao_e_equacoes.py`: etapas de cálculo e preparação dos documentos.
- `imprimir_completos.cjs` e `imprimir_formulas.cjs`: impressão/renderização de páginas HTML.
- Arquivos `.html`: conteúdo intermediário de equações e resolução.
- Imagens `.png` e `.jpg`: páginas e capturas usadas para revisão visual.

## `template/`

- `criar_template.py` e os demais scripts Python: etapas de adaptação e ajuste do documento.
- `artifact.md` e `manifest.json`: registros técnicos da adaptação.
- `referencia/template.pdf`: versão renderizada do modelo usado como referência.
- Imagens `.png` e `.jpg`: revisões e conferências das páginas.

Estes arquivos permanecem no repositório para documentar o processo. Nomes como `check`, `revisao`, `final` e `entrega` indicam estágios da conferência; a versão de entrega é o PDF na raiz.
