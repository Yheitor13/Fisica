# Orientações para os trabalhos de Física

- Consultar o README do trabalho ativo e apoio/referencias_gerais/README.md antes de iniciar uma etapa.
- Aplicar as orientações de apoio/referencias_gerais/INSTRUCOES_TRABALHO_FISICA.md conforme o pedido atual.
- Preservar medições e correções do usuário. Ler novamente a planilha salva antes de cada análise; não reconstruí-la a partir de transcrições antigas.
- Um experimento pode servir de base a outro. Registrar origem, unidades, incertezas e condições de validade dos dados reutilizados, sem presumir equivalência entre experimentos.
- Guardar materiais comuns em apoio/referencias_gerais/ e roteiros específicos no trabalho correspondente. Preservar arquivos e links históricos do trabalho 01.
- No trabalho 02, x é distância em cm (10, 20, ..., 90), e t é tempo em segundos. Aguardar o roteiro específico antes de iniciar a análise.
- Atualizar o índice e o GitHub ao concluir etapas relevantes durante o trabalho ativo, como organização, dados conferidos e resultados revisados. Conferir o diff, preservar alterações alheias e excluir temporários do Office. Não fazer push forçado.
- Não substituir nem renomear uma planilha aberta no Excel; aguardar salvamento e fechamento.
