## Organização e continuidade

As referências comuns da disciplina ficam em `referencias_gerais/`. Cada trabalho mantém seu roteiro, dados e resultados próprios. O acervo original do trabalho 01 foi preservado para manter os links e registros históricos.

Um experimento pode fornecer métodos, calibrações ou resultados para outro. Ao reutilizar algo, identificar o trabalho e arquivo de origem, a grandeza, unidade, incerteza e condições de validade. O trabalho 02 poderá usar o primeiro como base; a dependência concreta será definida após receber seu roteiro.

Atualizar este índice e o GitHub ao concluir etapas relevantes, após conferir os arquivos e excluir temporários do Office. Não publicar cálculos provisórios como resultados finais.
