# Reprodução do EX03

`calculos_verificados.json` mantém resultados em precisão completa; `verificacao_independente.json` registra o cálculo independente a partir da planilha salva. `graficos/` contém as exportações da Calculadora de gráficos. Os quatro CSVs contêm X, vX, Y, vY para as diferentes orientações. O código principal de cálculo é `../../apoio/calculadora-fisica/freefall.js`.

Para repetir a análise, sempre leia novamente `../refs/medidas_fisicaEX03.xlsx`. Os arquivos de desenvolvimento da conversa não substituem essa fonte.
